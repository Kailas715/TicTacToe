# TicTacToeGame

## Description
A simple Python-based Tic Tac Toe game. It solves the problem of creating an entertaining experience to users.

## How to Run
1. Install Python
2. Run the file:
   python TicTacToeGame.py

## Features
- Two-player game
- Win detection
- Simple CLI interface
